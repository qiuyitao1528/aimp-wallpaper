## 概述
AIMP 动态壁纸工具的第二个公开预发布版本（Beta）。本版聚焦设置项粒度与歌词显示质量。

## 本版变更
- **歌词显示**
  - 长歌词行自动缩小字号以适配窗口宽度，不再被窗口边缘截断；缩至字号下限仍超出时以省略号收尾
  - 调整歌词字号、字体或窗口宽度后即时重绘，此前需要等待切换歌词行才生效
  - 新增显示模式：当前行+下一行 / 仅当前行（仅当前行时译文保持高对比度）
  - 新增跟随目标：跟随频谱面板 / 跟随壁纸文字区 / 屏幕右下固定
  - 歌词窗口宽度、频谱面板宽度与高度可独立调整
- **设置界面**
  - 补齐此前无界面入口的选项：文字总开关、背景压暗程度、频谱面板显隐、歌词窗口锁定、封面左边距
  - 壁纸页拆分为「壁纸」与「封面」两页，单页高度降低
  - 间距类选项更名为与实际作用一致（歌名行后间距 / 歌名折行间距 / 歌手·专辑·信息行间距）
  - 字体下拉不可手工输入；数值无效时在状态栏明确提示，不再静默忽略
  - 设置窗口单例，避免多窗口并发保存互相覆盖
- **性能**：字体实例缓存，减少每次渲染的字体文件加载

## ⚠️ 功能成熟度
- **桌面歌词：测试阶段**。歌词属新增功能，仍存在较多已知问题，稳定性低于壁纸与频谱面板。歌词仅从本地音频内嵌标签与同目录 `.lrc` 文件读取，不联网检索；简繁语言自动判定可能不准，可在「设置 → 面板 → 歌词多语言优先」手动指定。如遇显示异常，可在设置或托盘菜单中暂时隐藏歌词。
- 壁纸渲染、频谱面板、主题跟随、暂停反馈等功能已相对稳定。

## 系统要求
Windows 10 / 11（64 位），AIMP v5.40（无需安装插件）

## 说明
本版本为预发布（Beta），功能与配置项可能调整，欢迎反馈问题。
