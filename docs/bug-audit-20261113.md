## 第三轮（2026-11-14，对抗性排查"退出/恢复/并发写"恶性路径）

| # | 模块 | 问题 | 后果 |
|---|---|---|---|
| R21 | __main__._quit_app | **恢复原壁纸与 worker 最后一轮渲染并发**：恰在切歌瞬间退出，恢复会被渲染覆盖回去 | 退出后桌面留渲染图，"恢复原壁纸"失效（恶性） |
| R22 | config.save | 多线程并发 save 共用同一个 .tmp | 互相截断 → os.replace 装进半截文件（数据损坏） |
| R23 | config.save | Windows 并发 replace 同一目标瞬态 PermissionError | 保存偶发失败（加 6 次重试） |
| R24 | aimp_api._send_timeout | SendMessageTimeoutW 回值未按 64 位声明 | LRESULT 截断（潜在属性回值错误） |

修复：退出顺序改为 `stop.set() → 等最后一轮落地(round_done, ≤2s) → 恢复`；worker 的 render 闭包
检查 stop（迟到轮不落盘）；config tmp 按线程 id 唯一 + replace 重试。
追加实测：audit_checks #47–#49。**总量：49 项编号实测，全绿。**

残余风险（无法离线实测，需发版后真机验证）：多屏真机行为、睡眠/唤醒全链路、AIMP 其它版本
共享内存差异、显示器热插拔。
